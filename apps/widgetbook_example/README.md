# Restage Widgetbook workbench

A small Flutter web app that runs the Widgetbook workbench generated by
[`restage_widgetbook_example`](../../packages/restage_widgetbook_example). It
holds no widgets or stories of its own; everything comes from that package.

Part of [Restage](https://restage.dev), server-driven UI for Flutter.

## Run it

Generate the stories first, from the example package:

```sh
cd ../../packages/restage_widgetbook_example
dart run build_runner build
```

Then run or build the workbench from this directory:

```sh
flutter run -d chrome
flutter build web --no-tree-shake-icons
```

The release build needs `--no-tree-shake-icons` because the workbench includes the RFW runtime, which
builds icons from runtime values.
