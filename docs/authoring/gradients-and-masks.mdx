---
title: Gradients and masks
description: Author gradient text, icons, fading edges and color filters in ordinary Flutter.
---

Write gradients and masks with Flutter's `ShaderMask` and `ColorFiltered`. Restage compiles the gradient, blend mode and child into surface data. The app creates the shader when it renders the surface.

## Gradient text and icons

```dart
ShaderMask(
  blendMode: BlendMode.srcIn,
  shaderCallback: (bounds) => const LinearGradient(
    colors: [Colors.indigo, Colors.pink],
  ).createShader(bounds),
  child: const Text(
    'Explore something new',
    style: TextStyle(color: Colors.white, fontSize: 32),
  ),
)
```

The same form works around an icon:

```dart
ShaderMask(
  blendMode: BlendMode.srcIn,
  shaderCallback: (bounds) => const SweepGradient(
    colors: [Colors.indigo, Colors.pink, Colors.indigo],
  ).createShader(bounds),
  child: const Icon(Icons.star, color: Colors.white, size: 64),
)
```

Both compile to a mask with a gradient map and the `srcIn` blend mode. Linear, radial and sweep gradients keep their colors, stops and geometry.

A closure with a single `return` works too. The gradient can be inline, `const`, a same-file const identifier or a `static const` field.

## Fading edges

```dart
ShaderMask(
  blendMode: BlendMode.dstIn,
  shaderCallback: (bounds) => const LinearGradient(
    begin: Alignment.topCenter,
    end: Alignment.bottomCenter,
    colors: [Colors.transparent, Colors.white, Colors.white, Colors.transparent],
    stops: [0, 0.15, 0.85, 1],
  ).createShader(bounds),
  child: const Column(
    children: [Text('Today'), Text('Yesterday'), Text('Last week')],
  ),
)
```

`dstIn` keeps the child's colors and uses the gradient's alpha to fade them. To fade the edges of a scrolling list, put the same mask around a bounded list.

## Radial vignettes

```dart
ShaderMask(
  blendMode: BlendMode.modulate,
  shaderCallback: (bounds) => const RadialGradient(
    colors: [Colors.white, Colors.black],
    radius: 0.8,
  ).createShader(bounds),
  child: Image.asset('assets/landscape.png'),
)
```

This compiles to a radial mask over the image widget. `center`, `radius`, `focal`, `focalRadius` and `tileMode` use Flutter's values.

## Rotation and tint

A `GradientRotation` becomes the mask's rotation in radians:

```dart
ShaderMask(
  blendMode: BlendMode.srcIn,
  shaderCallback: (bounds) => const LinearGradient(
    colors: [Colors.indigo, Colors.pink],
    transform: GradientRotation(0.5),
  ).createShader(bounds),
  child: const Text('A new direction'),
)
```

For a solid tint, use a color filter:

```dart
ColorFiltered(
  colorFilter: const ColorFilter.mode(Colors.teal, BlendMode.modulate),
  child: Image.asset('assets/landscape.png'),
)
```

`ColorFilter.mode` compiles to a color mask that behaves like Flutter's color filter. Every Flutter blend mode works.

## Effects that render from your app

Other shader callback bodies render from your app. The `ShaderMask` stays in your compiled code, and `restage build report` gives the reason. These render from your app:

- `ui.Gradient`, `ImageShader`, bounds calculations and stored shaders.
- Callbacks with more than one statement.
- Transforms other than `GradientRotation`.
- Color filters other than `ColorFilter.mode`, including matrices.

A design can't change those effects over the air. Extract one into a [custom widget](/authoring/custom-widgets) if you want editor controls for it.

For fragment shaders and image-filled text, see [Shaders and image effects](/authoring/shaders-and-image-effects).
